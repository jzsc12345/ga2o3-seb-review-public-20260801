# Lightweight project review subset

This directory contains ten explicitly selected deck/source review copies, one analysis script,
and six lightweight evidence artifacts. Five deck copies have runtime paths replaced by relative
`restricted_inputs/` placeholders. Physical parameter statements were not changed, but the copies
are intentionally not self-contained production inputs.

The evidence summaries make parser-only and spatial claims. They do not establish a completed
Wang 2026 fit and do not authorize RUN121 or any new run.
