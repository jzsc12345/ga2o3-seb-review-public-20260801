# Lightweight project review subset

This directory contains ten explicitly selected deck/source review copies, one analysis script,
and six lightweight evidence artifacts. Five deck copies have runtime paths replaced by relative
`restricted_inputs/` placeholders. Physical parameter statements were not changed, but the copies
are intentionally not self-contained production inputs.

Those six earlier evidence artifacts make parser-only and spatial claims. They do not establish a
completed Wang 2026 fit, and their historical statements did not authorize RUN121 or any new run.

The [RUN121 evidence bundle](evidence/RUN121/RUN121_RESULT.md) was added later under a separate,
bounded direct user instruction. It contains the sanitized result report, timeline boundary,
parent/candidate review copies, full deck diff, A14 images, four derived figures, compact numerical
tables, and hash inventories. Raw STR files, simulator logs, terminal transcripts, and heatmap or
native-vertex input grids are intentionally omitted.
