# Ga2O3 SEB public review mirror

This public repository is a sanitized review surface for the Wang2026
beta-Ga2O3 lateral E-mode MOSFET SEB reproduction project.

## Start here

1. Read `REVIEW_ENTRY.md` for the non-negotiable audit questions.
2. Read `04_reports/Ga2O3_SEB_有效进展与拟合审计_20260801.md`.
3. Inspect `01_claude_pre_cutoff/knowledge/` for the parameter/model basis.
4. Inspect `02_lightweight_project/decks/` and the matching RUN CSV/PNG evidence.
5. Read `03_codex_harness/docs/product-specs/Wang2026_fit_contract.md` before
   accepting any claim of a successful fit.

## Deliberate exclusions

The private repository remains the archival source. This public mirror excludes
recovered chat history, raw PDFs, STR/LOG files, secrets, and the 209-document
post-cutoff quarantine mirror. It also excludes legacy pre-cutoff decks that
contain coefficients later prohibited by the user. Current lightweight RUN
decks remain available under `02_lightweight_project/decks/`.
