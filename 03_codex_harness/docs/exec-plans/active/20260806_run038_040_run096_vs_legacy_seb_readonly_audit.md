## 1. 待解决的问题

比较以下五组结果：

1. RUN038；
2. RUN039；
3. RUN040；
4. RUN096；
5. 用户指定的历史正确案例：
   `/root/Desktop/sharer24/SEB/def/x=10um--T30min_meshcu`。

目标是解释：为什么历史案例后期能够形成漏极电流与源极电流大小接近、方向相反，而
RUN038–040 和 RUN096 主要只表现出漏极电流与栅极电流大小接近、方向相反，或者只出现
早期电荷收集阶段，没有进入后续源—漏导电阶段。

这里的“相等”均指电流大小接近、符号相反，不是漏极电压等于栅极电压。

## 3. 默认分析口径

若用户没有另行修改，采用以下口径：

- 使用基线扣除电流：`ΔIk(t) = Ik(t) - Ik(t < tstrike)`；
- 保留 ATLAS 原始符号；
- 电流统一换算为 A/µm，并记录原始单位和宽度换算；
- 相对误差不超过 10% 时，称为“大小接近、方向相反”；
- 文件名中的 VDS、xion、tstop 不作为到站证据；
- 只认日志中的 accepted 偏压、accepted 时间、实际 STR 和 CSV；
- 缺少证据时写 `NOT_EVALUABLE`，不得插值或推测。

三项计算量：

```text
err_DG  = |ΔId + ΔIg| / max(|ΔId|, |ΔIg|)
err_DS  = |ΔId + ΔIs| / max(|ΔId|, |ΔIs|)
err_KCL = |ΔId + ΔIs + ΔIg| / max(|ΔId|, |ΔIs|, |ΔIg|)
```

当分母接近零时，该点标记 `NOT_EVALUABLE`。

## 4. 先检查是不是“仿真时间或输出不够”

每组都应读取现有结果的真实时间范围，至少检查：

- 打击前；
- 1 ps；
- 10 ps；
- 100 ps；
- 1 ns；
- 5 ns；
- 10 ns；
- 100 ns；
- 现有结果的最晚 accepted 时间。

没有精确时间点时，只能使用最近的 accepted solution，并报告其真实时间。

先判断两个阶段是否存在：

### 阶段一：初始载流子分离与电荷收集

- `ΔId ≈ -ΔIg`；
- 源极响应较小；
- 栅极电流随后回落。

出现这一阶段本身不是错误。它可能只是 SEB 瞬态的早期阶段。

### 阶段二：源—漏持续导电路径

- `ΔId ≈ -ΔIs`；
- `ΔIg` 明显回落；
- 源—漏电流持续一段时间；
- 三端 KCL 同时成立。

如果 RUN038–040 或 RUN096 的日志在阶段二出现前已经停止，则优先裁决为“时间窗口或
accepted 输出不足”，不能直接归因于材料参数。

## 5. 必须逐组登记的原始证据

| 对象 | 必须定位的文件与事实 |
|---|---|
| 输入 | 实际 `.in`、SEU `.c/.lib` 或内建 SINGLEEVENTUPSET 配置 |
| 静态母态 | 真实 VGS、真实 accepted VDS、打击前 Is/Id/Ig |
| 瞬态 | 主 `.log`、accepted solution/SSF、真实终止时间 |
| 空间结果 | 关键时刻 `.str`，尤其是粒子路径、电子、空穴、电场、impact |
| 数值状态 | 正常结束、Cannot trap、缩步退出或中途停止 |
| 输出 | 已有 CSV、PNG 及其生成方法 |

报告不得用旧 handoff 或聊天摘要代替上述原始证据。
