# Core Beliefs

1. **模型运行成功不等于物理拟合成功。** parser、mesh、静态准入、瞬态和论文拟合是五个门。
2. **输入对齐和输出对齐必须分开。** 几何、LET、电荷对齐后仍可能没有持续电子通道。
3. **负结果有价值，但不能越权。** 单变量效应很小，只能排除该旋钮，不能证明另一机制正确。
4. **历史 SHA 高于叙述。** RUN deck、CSV、PNG 的冻结哈希优先于后写 handoff。
5. **可见性是反馈回路，不是求解器本身。** tmux 发射与只读可见监控窗分开。
6. **隔离优先于删除。** 后期文档先进入 imported 隔离层，经过核验再提升为研究结论。
