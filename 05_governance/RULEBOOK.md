# 截止日前历史工作流规则（Claude 工作区编译版）

> 这不是当前用户指令的替代品。它保留截止日前形成且未被现行规则撤回的工作方法；每条规则的
> 精确来源在 `RULE_PROVENANCE.csv`，历史废案在 `SUPERSEDED_RULES.md`。
>
> **孤立读取本文件无效**：必须同时读取 `../precedence.md` 与 `SUPERSEDED_RULES.md`。本文件不授予
> SSH、VM、ATLAS、DeckBuild、Victory*、许可证、删除、覆盖或任何 RUN 发射权限。
>
> **封印范围不是“全部历史聊天”**：本版只封印 `CANDIDATE_UNIVERSE.json` 明确列举的
> `CR-001..CR-016` 与 `SR-001..SR-009` 共 25 个编译规则产物。它不声称穷举截止日前消息里的
> 每个规范性命题；完整历史抽取若开展，必须另建 universe，不能反向改变本版计数。

## 证据与诊断

### CR-001 — “已核实”必须带现场证据

只有能给出原始命令输出、材料库行、手册页码、例子行或运行证据，才可写 `[已核实]`；查不到
必须写 `[未核实]`。文件里已有一句相同的话不能替代本轮核验。

### CR-002 — 120 K 先做 A/B 定性

先区分 120 K 是 Newton 失败过程的瞬时下冲，还是某个已收敛步骤的真实解。前者查耦合求解，
后者先查热边界；必须输出完整 T–V 轨迹、折半位置、热极 `ext.temp/alpha` 和冷点空间位置。

### CR-003 — 一次只改一个变量

每轮记录假设、唯一改动、预先判据、结果和下一步。结构、源项、物理模型与时间步混改所得曲线
不能归因。

### CR-004 — 运行同时留痕

长求解运行期间并行修文档或阻塞项；每个关键动作落文件，不能只在聊天界面留下结论。

### CR-005 — 报错先查证据链，不猜参数

先提取错误指纹与已有失败经验，再按材料库 → 手册 → 例子 → 论文查证；没有已知解时提出
若干有证据的候选并逐个验证。

## 计划与执行

### CR-006 — 方案先对抗评审再冻结

多候选或新阶段必须让独立评审提出至少三条证据化异议，并明确指出用户/提案前提中最可能错的
一条；没有异议的评审不合格。

### CR-007 — 冻结计划与执行分离

评审档负责查证、反驳与冻结；执行档只按冻结变量、判据和停止条件做，不现场扩展物理范围。

### CR-008 — 用户建议先过冲突门

用户建议可能缺少实时上下文。先与固定 handoff、现行账本、活动计划和原始运行证据对照；冲突
时给原计划、新建议、折中方案及代价，用户明确重定向后才改变未来动作。

### CR-009 — 已验证步骤不重跑

已经通过且有证据的结构步不重跑、不顺手优化，保留自检 grep。截止日后的“断流恢复/不重启
在飞进程”纪律属于当前用户指令，不冒充本历史规则。

## RUN 与可观测性

### CR-010 — 每轮一个 RUN 收纳箱

每次仿真迭代使用 `RUNnnn_<tag>`，发射前 A14 四件缺一不可：结构图、网格图、完整 deck diff、
tmux 会话名；到站报告包含空间图、曲线与路径索引。

### CR-011 — 长任务走 tmux 正规 runner

禁止裸跑 `ssh ... deckbuild`。长任务必须通过既有 tmux 封装，成败认 `typescript` 内 simulator
exit 证据；治理脚本和 runner 名称不得被 GUI 历史名字误导。

### CR-012 — 主产线是 DeckBuild 三层闭环

主 deck + `aux.in` SWEEP/EXTRACT + tmux 跑批；采样由 LHD 生成 list，收数后以 BV↑/Ron↓ 的
Pareto 前沿收缩参数箱。VictoryDoE 属历史废案。

### CR-013 — 物理改动必须核签

不得为了收敛私自关闭 `lat.temp/κ(T)`、impact、trap 或 incomplete；违规所得整轮结论
作废。物理改动发射前提交差分和判据，得到用户核签后才运行。

### CR-014 — 版本更新后的首会话预检失败就停止

桌面应用版本更新后的首个会话，先过强制开机复述、应用资产核对、preflight L0 和快照对表；
任一门失败不执行实弹操作。

## 沟通与交付

### CR-015 — 30–60 分钟给可视进展

进展不能只有“运行中”。优先给结构、网格、电场/温度/电流密度空间图，再给曲线；缺图应标出
绝对待填路径和图注。

### CR-016 — 每轮留下可选下一步

阶段结论末尾给 2–4 个带代价说明的可选下一步；批评必须带证据，附和与反对都不能只靠语气。
